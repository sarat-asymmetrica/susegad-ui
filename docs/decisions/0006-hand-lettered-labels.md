# 0006: hand-lettered display labels may be lowercase

*Sutradhar, 24 September 2026, Wave 0 review. Status: accepted.*

The charter asks for sentence case. A few short display labels are set in the hand face (Kalam) as if written in pencil: the kicker "a front-end library, drawn in code in Goa", "the prompt", "how the words become code", "one line, never lifted". Lowercase is part of that handwriting, the way a note in a margin is written.

Decision: lowercase is allowed only for short labels set in `--sg-font-hand`, never for headings, buttons, form labels, errors or body copy. Screen readers read them the same either way. Everything else stays in sentence case.
