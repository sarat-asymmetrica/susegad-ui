one page, three ways

Start here

From an empty folder to one page with a drawing, a card and a footer. Pick whichever of the three ways suits you; they all arrive at the same place. The sample here is a homestay in Aldona, but any page of yours will do.

The goal

One file, index.html, in a folder with nothing else in it. When you are done, opening it shows the Paus drawing (rain on a window, drawn live), a small card of status, and a footer that says who made the page.

Way 1: by hand

Make an index.html and paste these lines into it:

<!doctype html>
<html lang="en" data-register="warm">
<head>
  <meta charset="utf-8">
  <title>A homestay in Aldona</title>
  <link rel="stylesheet" href="https://susegad.asymmetrica.ai/packages/tokens/tokens.css">
</head>
<body>
  <sg-scene name="paus" register="warm">
    <h2>Monsoon at the window</h2>
    <p>The river runs high, the veranda smells of wet earth.</p>
  </sg-scene>
  <p><sg-badge tone="info" busy>Two rooms free for December</sg-badge></p>
  <footer>
    <p>Made with Susegad UI, in Aldona.</p>
  </footer>
  <script type="module">
    import "https://susegad.asymmetrica.ai/packages/core/index.js";
    import "https://susegad.asymmetrica.ai/packages/scenes/paus/index.js";
    import "https://susegad.asymmetrica.ai/packages/components/badge/badge.js";
  </script>
</body>
</html>

Save, open the file in a browser, and the rain falls. The data-register on <html> sets the mood for the whole page; change warm to quiet and the drawing stills into a frame.

Way 2: with the CLI

The command line copies the pieces into your project, where they become your code. Change anything you like afterwards.

npx susegad add scene-paus sg-badge --dir src/lib

Your folder now holds src/lib/susegad/ with the scene, the badge and everything they stand on. The same page then reads:

<script type="module">
  import "./src/lib/susegad/core/index.js";
  import "./src/lib/susegad/scenes/paus/index.js";
  import "./src/lib/susegad/components/badge/badge.js";
</script>

susegad list shows everything on the shelf, and susegad info scene-paus explains one piece before you take it.

Way 3: with an agent

Give your coding agent the library's SKILL.md from the top of the repository and say what you want, the way you would say it to a person. The skill carries the register, the install lines and the scene contract, so the agent lands on the same page this walkthrough does. A prompt that works:

Build me a single page for a homestay in Aldona. Use Susegad UI: the paus scene over the top, a badge for room availability, and a quiet footer. The register is warm.

The susegad skill command installs that skill into your agent's folder for you: npx susegad skill --harness claude --global. An MCP server that speaks the registry directly is on its way.

What you should see

A page where rain runs down a window and your words sit calm inside it. A badge that says what is still happening. A footer with your name on it. From there: every piece has its own page on this site, with its prompt, its demo and its install line. Start with Scenes, or look the techniques up in the pencil box.
