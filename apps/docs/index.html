Susegad UI

Konkani, from the Portuguese sossegado.

Susegad UI is a library for interfaces and documents that are beautiful and comfortable at the same time. It grew out of a sketchbook of code-drawn studies of Goa and India, and it keeps their craft: drawings that host your words, show something real and answer the person using them. Every piece comes in three registers, ships with the prompt you could give an AI agent to make it, and keeps its keyboard and screen reader support in a plain core underneath.

What is inside

Every piece has a page of its own, with its prompt and its install line. The indexes show a still of each; the drawing runs when you open it.

Three ideas

  1. One component, three registers

    Every piece has a quiet, warm and playful register, set for the whole page the way colour mode is. The same progress bar is a pencil hairline for an ERP buyer, a kolam that closes for a homestay, and a string of bunting that fills up for a festival. Try the register switch at the top of this page. The whole page changes, not just the drawings.

  2. Every component ships with its prompt

    Next to the code sits the prompt you could give an AI agent to make it, and a map from the words in that prompt to the techniques in the code. The library teaches as it serves. Each scene's page carries its prompt on a blue inland letter you can copy, with the map folded away just after it.

  3. Behaviour and skin are separate

    Keyboard, focus and screen reader support live in a headless core that is boringly correct. The theatre is a skin on top. The quiet skin has to pass an accessibility audit without a single flourish, and every drawing also says what it shows in text.
