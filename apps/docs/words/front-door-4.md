# Words for the front door, fourth edition (three doors)

Draft by the builder, 12 October 2026 (the strings as built live in `apps/docs/words.core.js` under `W.audience`, in `index.html` and in `start.html`; where this draft and the code differ, the code is newer), for `batch/site-overhaul`, for Kathakar's pass. Request: `docs/requests/2026-10-12-front-door-4.md`. Register for the site's own chrome: warm, plain. Sentence case. No em dashes. No urgency. No marketing adjectives.

The first reader is someone who wants a page and does not write code. Words above the first developer link avoid: register, headless, component, primitive, token, kernel, registry, CLI, MCP. (Use "look", "mood", "piece", "page".)
